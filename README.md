# OPEN-AI: Use Claude & ChatGPT For Free 🚀

Welcome to the **OPEN-AI** repository! This project provides access to premium AI models, including Anthropic's Claude and OpenAI's ChatGPT, completely free of charge.

## 📱 Features
* **Free Access:** Use advanced AI models without requiring a paid subscription or API keys.
* **Premium Models:** Chat with top-tier assistants like ChatGPT and Claude.
* **Mobile Ready:** Designed for quick deployment and on-the-go usage.

## 📦 What's Inside?
* **`OPEN AI.apk`**: The official Android application package for the project. Download and install it directly on your Android device to start chatting.

## ⚙️ Installation Guide

Follow these quick steps to get started on your mobile device:

1. **Download the App:** Click on the `OPEN AI.apk` file inside this repository and select **Download raw file**.
2. **Enable Unknown Sources:** If prompted by your Android device, temporarily allow installations from your browser or file manager in your phone's settings.
3. **Install & Run:** Open the downloaded `.apk` file, complete the setup wizard, and launch the application.
